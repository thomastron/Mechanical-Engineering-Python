# Python packages for the "Python for the Design Desk" map in README.md.

# Not included: GXBeam (a Julia package, not Python) and FEniCSx (no pip wheels;

#   (pulled in by EasyFEA and calfem-python) needs libGLU and libXft
#   (Debian/Ubuntu: sudo apt install libblas3 liblapack3 libglu1-mesa libxft2)
